БОТ УЖЕ ПРИВЯЗАН К @Ksu_payment_bot — TELEGRAM TOKEN ВШИТ.

КОД ПРАВИТЬ НЕ НУЖНО.

1. Загрузи содержимое этой папки в PRIVATE GitHub-репозиторий.
2. Добавь в GitHub Secrets три значения:
   CLOUDFLARE_ACCOUNT_ID
   CLOUDFLARE_API_TOKEN
   WORKER_GITHUB_TOKEN
3. Запусти Actions → Deploy Telegram webhook worker → Run workflow.
4. После зелёной галочки отправь боту:

   /claim KSU-CTPWT34R

5. Потом открой /settings.

Подробно: ЗАПУСК_БЕЗ_КОДА.md
