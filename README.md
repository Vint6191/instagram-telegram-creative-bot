# Instagram → Telegram Creative Bot — preconfigured build

Этот архив уже привязан к боту `@Ksu_payment_bot`: Telegram token намеренно встроен в код по просьбе владельца.

> Репозиторий обязательно должен быть **PRIVATE**. Не публикуй архив и репозиторий открыто.

## Что делает бот

```text
сотрудник отправляет одну Instagram-ссылку боту
        ↓
бот проверяет доступ и выбранный канал/группу
        ↓
GitHub Actions скачивает Reel / пост / карусель
        ↓
медиа публикуется в Telegram со статистикой аккаунта и поста
```

Никаких тегов, категорий, обновления статистики, поиска и управления производством.

## Настройки внутри Telegram

Владелец может:

- назначать сотрудников одноразовым приглашением;
- отзывать доступ;
- выбрать группу командой `/settarget` внутри неё;
- выбрать канал, переслав боту любой пост из этого канала.

## Первый запуск владельца

После успешного деплоя открой `@Ksu_payment_bot` и отправь:

```text
/claim KSU-CTPWT34R
```

Команда работает один раз. После неё открой:

```text
/settings
```

# Развёртывание без редактирования кода

Подробная пошаговая инструкция для человека без опыта находится в файле:

```text
ЗАПУСК_БЕЗ_КОДА.md
```

Потребуются только три GitHub Secret:

| Secret | Для чего |
|---|---|
| `CLOUDFLARE_ACCOUNT_ID` | ID аккаунта Cloudflare |
| `CLOUDFLARE_API_TOKEN` | автоматический деплой Worker и создание KV |
| `WORKER_GITHUB_TOKEN` | запуск workflow скачивания из Telegram |

Опционально:

| Secret | Для чего |
|---|---|
| `INSTAGRAM_COOKIES_B64` | доступ к постам, которые Instagram не отдаёт без авторизации |

Telegram token, webhook secret, setup token и код первичного владельца уже встроены. Числовой Telegram ID вводить не нужно.

## Архитектура

- **Cloudflare Worker** — Telegram webhook, права пользователей и настройки.
- **Cloudflare KV** — владелец, сотрудники, приглашения и выбранный канал.
- **GitHub Actions** — временный загрузчик Instagram и FFmpeg.
- **Telegram** — конечное хранилище креативов.

Worker запускает GitHub workflow через fine-grained GitHub token. Сам тяжёлый код в Cloudflare не выполняется.

## Команды

### Владелец

- `/claim КОД` — однократно назначить первого владельца;
- `/settings` — открыть настройки;
- `/invite` — создать приглашение;
- `/users` — список сотрудников;
- `/revoke TELEGRAM_ID` — отозвать доступ;
- `/settarget` — назначить текущую группу.

### Сотрудник

- `/join КОД` — активировать приглашение;
- после активации отправлять по одной Instagram-ссылке в личку боту.
