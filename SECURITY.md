# Security

Это специальная preconfigured-сборка: Telegram bot token намеренно встроен в исходники по прямой просьбе владельца.

Поэтому:

- репозиторий должен быть только PRIVATE;
- архив нельзя отправлять посторонним;
- GitHub collaborators должны быть доверенными;
- при утечке репозитория token нужно сразу перевыпустить в BotFather и заменить в `worker/src/preconfigured.ts` и `.github/workflows/process-instagram.yml`;
- GitHub и Cloudflare tokens по-прежнему хранятся только в GitHub Secrets и не встроены в проект.

Первый владелец назначается одноразовой командой `/claim`. После записи владельца в KV повторно захватить управление через код первичной настройки нельзя.
