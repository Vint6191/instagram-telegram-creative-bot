# Запуск без ковыряния в коде

Тебе не нужно открывать `.py`, `.ts`, `.yml` или менять конфиги. Всё делается через сайты GitHub и Cloudflare.

## 1. Создай приватный репозиторий GitHub

1. На GitHub нажми **New repository**.
2. Название, например: `instagram-creative-bot`.
3. Обязательно выбери **Private**.
4. Создай репозиторий.
5. Нажми **uploading an existing file**.
6. Перетащи туда **содержимое папки проекта**, а не сам ZIP.
7. Нажми **Commit changes**.

## 2. Создай бесплатный аккаунт Cloudflare

После входа открой главную страницу аккаунта и скопируй **Account ID**.

## 3. Создай Cloudflare API Token

В профиле Cloudflare открой **API Tokens → Create Token**.

У токена должны быть права на этот аккаунт:

- Workers Scripts: Edit;
- Workers KV Storage: Edit;
- Workers Scripts: Read или эквивалентное чтение Worker-настроек.

Ограничь токен только своим аккаунтом Cloudflare и скопируй его сразу после создания.

## 4. Создай GitHub token для запуска Actions

В GitHub открой:

```text
Settings → Developer settings → Personal access tokens → Fine-grained tokens
```

Создай token только для репозитория бота.

Repository permissions:

```text
Actions: Read and write
Metadata: Read
```

## 5. Добавь три секрета в GitHub

Открой репозиторий:

```text
Settings → Secrets and variables → Actions → New repository secret
```

Добавь:

```text
CLOUDFLARE_ACCOUNT_ID
CLOUDFLARE_API_TOKEN
WORKER_GITHUB_TOKEN
```

В значения вставь соответственно:

- Cloudflare Account ID;
- Cloudflare API Token;
- fine-grained GitHub token.

## 6. Запусти деплой

Открой в репозитории:

```text
Actions → Deploy Telegram webhook worker → Run workflow
```

Workflow сам:

- создаст Cloudflare KV;
- подставит GitHub repository owner/name;
- задеплоит Worker;
- запишет GitHub token в Worker secret;
- установит Telegram webhook;
- зарегистрирует команды бота.

Зелёная галочка означает, что бот поднят.

## 7. Назначь себя владельцем

Открой в Telegram `@Ksu_payment_bot` и отправь:

```text
/claim KSU-CTPWT34R
```

Потом:

```text
/settings
```

## 8. Назначь канал или группу

### Канал

1. Добавь бота администратором канала.
2. Дай право публиковать сообщения.
3. Перешли любой пост из этого канала боту в личку.
4. Нажми **Назначить**.

### Группа

1. Добавь бота в группу.
2. Дай право отправлять сообщения и медиа.
3. Напиши в группе:

```text
/settarget
```

## 9. Добавь сотрудников

В боте открой:

```text
/settings
```

Нажми кнопку создания приглашения и перешли ссылку сотруднику. Она одноразовая.

## 10. Проверка

Отправь боту одну публичную ссылку на Reel или Instagram-пост. Бот должен ответить, что принял ссылку, а после GitHub Actions опубликовать медиа в выбранное место.

## Instagram cookies — только если понадобятся

Без cookies часть публичных публикаций может скачиваться, а часть Instagram может закрывать.

Когда понадобится авторизованная сессия:

1. экспортируй `cookies.txt` из отдельного технического Instagram-аккаунта;
2. запусти локально `scripts/encode-cookies.py`;
3. результат добавь в GitHub Secret `INSTAGRAM_COOKIES_B64`.

Этот пункт можно пропустить при первом запуске.
